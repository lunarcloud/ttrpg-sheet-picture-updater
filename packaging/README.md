# Packaging: `.deb`, `.rpm`, AppImage

These scripts build standalone Linux distribution artifacts from a
PyInstaller-frozen binary, so end users don't need Python/pip installed.
See the "Distribution / Packaging" section of `../plan.md` for full design
rationale.

## Build-time tools (not needed by end users)

- **PyInstaller** — already in `requirements-dev.txt`, installed by
  `./setup.sh`.
- **[`fpm`](https://github.com/jordansissel/fpm)** — required by
  `build-deb.sh`/`build-rpm.sh`. Requires Ruby. Install with:
  ```
  gem install --user-install fpm
  ```
- **`rpmbuild`** — required by `build-rpm.sh` in addition to `fpm` (fpm
  shells out to it for the `-t rpm` target). On Debian/Ubuntu build hosts:
  `sudo apt-get install rpm`. Not needed for `build-deb.sh`.
- **`appimagetool`** — required by `build-appimage.sh`. If not found on
  `PATH`, the script downloads a local copy to `packaging/tools/` (gitignored)
  automatically.

## Usage

From the repo root, with `.venv` set up (`./setup.sh`):

```
./packaging/build-deb.sh        # -> dist/packages/update-portrait_<version>_amd64.deb
./packaging/build-rpm.sh        # -> dist/packages/update-portrait-<version>-1.x86_64.rpm
./packaging/build-appimage.sh   # -> dist/packages/update-portrait-<version>-x86_64.AppImage
./packaging/build-all.sh        # builds all three
```

Version numbers come from the single `VERSION` file at the repo root — keep
it in sync with `update_portrait.__version__` when bumping.

## Icon

Only `icon/icon-source.png` is a committed file — a human-edited (or, until
real artwork is provided, a generated placeholder showing safe-zone guides)
master icon. Every other icon file (`icons/hicolor/**/apps/update-portrait.png`,
`appimage/icon.png`) is generated by `icon/generate_icons.py` and gitignored.
Project artwork must only be created/edited by a human — see
`../.github/copilot-instructions.md`.

## Build natively per architecture

`pikepdf` ships platform-specific compiled wheels, so PyInstaller must run
natively on each target OS/arch you want a package for — these scripts
assume a Linux x86_64 build host.
